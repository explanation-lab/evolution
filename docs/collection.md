# Evolution pilot collection

The hosted collection study is `collection/experiment1/index.html`, experiment version 1.0.0. The separate offline review at `code/experiment1/index.html` still supports double-clicking and downloading responses without uploading anything.

The collection copy uses the Console-converted frozen Explanation Lab client 1.5.1 and schema 2.0.0. It must be opened through a Console launch link. There is one within-participant launch group, `mixed`, with a pilot target of 45. Ducks come first; the other five case blocks are randomized without replacement. The two interactive blocks each contain consecutive prey and predator screens, yielding eight distinct explanation responses.

Consent refusal ends immediately without uploading. After the required feedback, the complete jsPsych trial array is saved. A failed save keeps the participant on a retry screen; a successful production save returns them to the Prolific completion URL configured for this study in the Console. The URL is deliberately not borrowed from another study. Sandbox runs save only sandbox data and display a saved confirmation.

Before recruitment, the researcher must finish manual sandbox review, add this pilot's own Prolific completion URL in the Console, review consent/payment details against the actual recruitment listing, and complete Console readiness checks before enabling Live.

The published `explanation-lab.config.json` is generated by the Console converter and must remain paired with this package. Stable response item IDs distinguish each species screen. Export mappings include age, gender, gender_other, race, race_other, ethnicity, college_biology, and evolution_course.
