# Pilot 2

Open `index.html` to review the self-contained jsPsych study. It uses the same bundled jsPsych 8.3.0, plugins, CSS, pictures, and forms as Pilot 1. No build or internet connection is needed. Responses can be downloaded as CSV or JSON at completion.

## Sequence

Consent, initial familiarity, and instructions precede:

1. A worked finch-beak example with an illustrative picture of beak-size variation, a scenario and question, and four short steps covering variation, differential survival/reproduction, inheritance, and population change.
2. Duck webbed feet, with the example no longer visible.
3. Gazelle speed, then cheetah speed.
4. Moth camouflage, then bird visual discrimination.
5. Goat horizontal pupils.
6. Saharan silver-ant hairs.
7. Giraffe necks as the final easy response.

Demographics, feedback, and the download screen follow. Every response screen has one required explanation box. The paired cases retain separate prey and predator screens and their original paired pictures. No stage is randomized, no deadline is imposed, and no feedback or model answer appears on response screens.

## Data

There are eight case-response trials and a separate worked-example trial. The example records viewing time and its image filename without being treated as a participant explanation. Data include version `2.0.1`, pilot `pilot_2`, training example `finch_beaks`, case order, stable item/species IDs, scenario and question text, response text, response time, and first-input latency. Case positions identify six blocks; paired screens also have their own within-case positions. All case responses use `explanation_1`.

This is the offline review package. The existing hosted Pilot 1 and its collection settings have not been replaced.

## Example reference

The finch example is a hypothetical illustration informed by the seed-availability, beak-size, survival, and inheritance findings summarized in [HHMI BioInteractive's finch materials](https://www.biointeractive.org/classroom-resources/effects-natural-selection-finch-beak-size). The text is newly written; no HHMI images or branding are included.
